# 中文维基 dump 采集与合并报告（v0.7）

## 目的
补上 CPT 语料的中文缺口：此前合并语料（v0.5）中文仅 28 篇（<0.1%），无法支撑中文制作意图。

## 数据获取
- 来源：`https://dumps.wikimedia.org/zhwiki/latest/zhwiki-latest-pages-articles.xml.bz2`
- 大小：3,452,366,696 bytes（3.45GB）
- 下载：8MB Range 分块续传（单连接），约 32 分钟；规避 429 与长连接降速
- 解析：`cpt/fetch_zhwiki_dump.py` v2（bz2 流式 + ElementTree iterparse + wikitext 清洗 + 强/弱关键词）

## 抽取与清洗
1. **第一遍**（`fetch_zhwiki_dump.py`）：扫到 640,000 页时停止，保留 **3,489 docs / 22.1M 字符**（强关键词命中或 ≥2 弱关键词）。
2. **第二遍**（`clean_zhwiki_raw.py`）：
   - 去掉残留标记（`[[`/`]]`/`{{`/`}}`/`&nbsp;`/空书名号/括号/引用编号/HTML 标签）；
   - 相关性筛选：标题含音乐/音频词 → 保留；标题命中黑名单（足球/哲学/政府/游戏/电影…）→ 丢弃；否则开头 400 字含音乐/音频词 → 保留；
   - 丢弃 2,195 条 off-domain（如德甲、海德格尔、电子政务等），最终 **1,294 docs / 6,805,658 字符 / ~3,579,350 tokens**，残留标记基本为 0（只有 25 篇含少量 `<`/`>`）。

## 结果（合并 v0.7）
输入：zhwiki-corpus-v2 + data-expanded + data-curated + data-permissive
- **71,627 docs / 120,729,147 字符 / ~32,083,379 tokens**
- train 70,231 / val 1,396
- 语言分布：中文 1,263 docs / 中英混合 382 / 英文 69,982
- 中文 token 占比：约 **11.2%**（3.58M / 32.08M）
- 许可分类：share-alike 65,644 docs / permissive 5,983 docs
- 去重：移除 64,950 条；无重复、无同源跨集

## 质量取舍
- v0.6 曾把 3,865 篇（25M 字符）中文全部并入，但抽样 60% 文档仍含 wikitext 残留，且混入大量非音乐条目（占比高）。
- v0.7 改为「质量优先」：中文从 25M 字符降到 6.8M 字符，但基本全部是音乐领域（乐理、乐器、录音、音频技术、音乐人/作品），中文 token 占比 11.2%，作为"中文音乐领域语感"补充足够。
- 如需更多中文（如 20%+），可继续扫 dump（当前只扫到 64 万页，全量约 150 万页），或加入中文维基教科书/文库与授权教材。

## 许可与署名
- 维基百科文本：**CC BY-SA 4.0**；每篇保留标题与永久链接；
- 合并语料整体按 CC BY-SA 4.0 分发；商用训练用 `cpt/data-permissive` 或按 `license_class` 过滤。

## 已知问题
- 关键词筛选是启发式，仍可能包含少量音乐人/专辑介绍（对制作知识价值有限，但提供中文音乐词汇）；
- wikitext 清洗仍有少量残缺（如被模板删掉的人名留下"由和共同完成"这类句子），比例低；
- `zh-wikipedia-dump` 尚未在 `cpt/sources.yaml` 注册（等另一路提交同步后补），当前以独立 corpus 输入方式合并；
- 扫描速度在长条目段会下降（约 200 pages/s），全量扫描需 1 小时以上。
